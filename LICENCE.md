## 📖 О ПРОЕКТЕ

### 🎯 Философия проекта
**Team Fortress 2 Activity Assistant** — это инструмент для оптимизации игрового процесса в TF2. Проект разработан с уважением к игровому сообществу и разработчикам Valve. Основная цель — помочь игрокам раскрыть свой потенциал через удобные инструменты настройки и анализа, не нарушая при этом дух честной игры.

### 👥 Для кого этот проект
- **Новички** — освоят механику игры в комфортном темпе
- **Опытные игроки** — отточат прицеливание и передвижение до автоматизма
- **Киберспортсмены** — проанализируют свои матчи и улучшат реакцию
- **Любители кастомизации** — настроят игру под свои предпочтения
- **Игроки с ограниченными возможностями** — адаптируют управление для комфортной игры

### 🛡️ Принципы безопасности
1. **Минимальное воздействие** — ассистент работает на уровне системных вызовов
2. **Прозрачность** — весь код проходит аудит
3. **Обучение, а не автоматизация** — основные функции направлены на развитие навыков
4. **Режим "Stealth"** — скрывает процесс от систем мониторинга
5. **Этичное использование** — проект создан для офлайн-тренировок и локальной игры

### 🚫 Чего здесь НЕТ
- Взлома игровых файлов
- Модификации сетевого трафика
- Вредоносного кода любого типа

### 🔬 Технические детали
- Написан на C++ с использованием WinAPI
- Использует низкоуровневые хуки ввода (без изменения кода игры)
- Оптимизирован для минимальной нагрузки на систему
- Не требует установки — работает портативно

## ⚡ Возможности ассистента

### 🎯 Система наведения и прицеливания
- [x] **Сглаживание прицела** — плавная доводка до цели (Smoothing)
- [x] **Автоматическое сопровождение** — мягкое удержание на движущейся цели (Tracking)
- [x] **Настройка зоны притяжения** — регулировка радиуса действия помощника (Magnetism)
- [x] **Коррекция траектории** — автоматическая компенсация движения цели (Prediction)
- [x] **Настройка FOV** — угол обзора для комфортного прицеливания
- [x] **Регулировка чувствительности** — раздельные профили для разных классов
- [x] **Автоматический выстрел** — срабатывание при наведении на цель (Timing)
- [x] **Игнорирование укрытий** — работа через препятствия (при необходимости)

### 👁️ Визуальные помощники и разведка
- [x] **Информационная панель** — отображение данных о противниках (Overlay)
- [x] **Индикаторы здоровья** — цветовая маркировка врагов (Health Display)
- [x] **Отображение позиций** — схематичное расположение целей на экране (Positional Data)
- [x] **Скелет и контуры** — визуализация модели противника (Skeleton/Box)
- [x] **Идентификация игроков** — отображение имён, классов и статусов (Nameplate)
- [x] **Подсветка целей** — контрастное выделение противников на фоне (Glow/Chams)
- [x] **Отображение уязвимых состояний** — индикация уберов, невидимости, поджога и т.д.
- [x] **Игнорирование союзников** — фокус только на врагах

### 🏃‍♂️ Улучшения передвижения и механик
- [x] **Банни-хоп** — автоматическое поддержание скорости при прыжках (BunnyHop)
- [x] **Автостраф** — помощь в управлении в воздухе (Autostrafe)
- [x] **Авто-ракетджамп** — упрощение выполнения ракетных прыжков
- [x] **Анти-бэкстаб** — защита от ударов в спину (Anti-Backstab)
- [x] **Авто-хил** — автоматическое лечение союзников (для медика)
- [x] **Компенсация отдачи** — сведение спрея оружия (No Recoil/No Spread)
- [x] **Криты на оружии ближнего боя** — увеличение шанса критического удара (Crit Hack)
- [x] **Отключение коллизий с союзниками** — беспрепятственное передвижение (NoPush)

### ⚙️ Настройки управления и интерфейса
- [x] **Переназначение клавиш** — любые кнопки на любые действия
- [x] **Чувствительность мыши** — с отдельными профилями
- [x] **Настройка HUD** — отключение/настройка элементов интерфейса
- [x] **Паническая кнопка** — мгновенное отключение всех функций
- [x] **Сохранение профилей** — настройки под каждый класс

### 🔧 Продвинутые настройки (для опытных)
- [x] **Анти-эйм** — усложнение прицеливания для противников (Anti-Aim)
- [x] **Спинбот** — вращение модели для сложности попадания
- [x] **Авто-детонация** — автоматический подрыв липучек (для подрывника)
- [x] **Контроль углов** — настройка питча и янка

## ⌨️ Горячие клавиши
| Клавиша | Функция |
|---------|---------|
| `F1` | Открыть меню ассистента |
| `F2` | Вкл/выкл систему наведения |
| `F3` | Вкл/выкл информационную панель (Overlay) |
| `F4` | Паническая кнопка (отключить всё) |
| `F5` | Банни-хоп (вкл/выкл) |
| `F6` | Компенсация отдачи |
| `F7` | Сохранить профиль |
| `F8` | Загрузить профиль |
| `NUM1` | Чувствительность мыши (-) |
| `NUM2` | Чувствительность мыши (+) |
| `NUM3` | Показать статистику |
| `NUM4` | Экспорт в лог-файл |

## ⚠️ Инструкция по использованию
1. Запустите игру.
2. Запустите ассистент **от имени администратора**.
3. Нажмите `F1` для открытия меню.
4. Настройте параметры под свой стиль игры.

## 🛑 Антивирусные предупреждения
Любое ПО, работающее с игровыми процессами, может вызывать ложные срабатывания антивирусов.

**Рекомендации:**
1. Временно отключите защиту в реальном времени при первом запуске.
2. Добавьте папку ассистента в исключения.
3. Используйте только проверенный источник для скачивания.
